Who I am.

Project 02 — Unreal Engine

The Forgotten Shrine

Completed

The Forgotten Shrine is an adventure game set around an ancient, atmospheric shrine. Its gameplay includes an Endless Runner section, which is part of this game rather than a separate project.

Game overview

A shrine-themed adventure built around a dramatic stone environment, ancient architecture and a strong sense of atmosphere.

Included gameplay — Endless Runner

The Endless Runner is a gameplay section within The Forgotten Shrine. It places the player on an elevated stone route with obstacles and a score display.

Development focus

Building the shrine environment, laying out the playable route, and combining character movement with obstacle-based gameplay.

Included gameplay section
Endless Runner

The running sequence belongs to The Forgotten Shrine. It features forward movement along a stone path, obstacles ahead and an on-screen score counter.
